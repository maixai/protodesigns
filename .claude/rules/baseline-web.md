# baseline-web:`targets` 含 `web` 时适用

叠加在 [`protodesign-baseline.md`](./protodesign-baseline.md)(跨端共享基线)之上。

## ① 响应式基线(多宽度必可用)

Web 原型的验证宽度**不是设备断点,而是浏览器窗口宽度区间**。以下宽度都**可用且不破版**(无横向溢出、无文字重叠、无内容被裁):

| 宽度 | 典型场景 |
| --- | --- |
| `375px` | 窄窗口 / 手机浏览器 |
| `768px` | 平板竖屏 |
| `1280px` | 笔记本 |
| `1600px` | 桌面大屏 |

- 用断点 / 媒体查询或栅格组件实现;小屏优先保证内容单列可读。
- 内容区设**最大宽度约束**并在宽屏居中,避免超宽屏下行长过长。

> 若该原型的 `targets` 同时含 `desktop`,窗口尺寸相关的验收以
> [`baseline-desktop.md`](./baseline-desktop.md) 为准(两端的宽度语义不同)。

## ② Web 专属检查项

| 项 | 要求 |
| --- | --- |
| 路由模式 | 若该原型的 Web 产物未来可能被套壳(桌面端),**优先用 hash 模式**,避免 `file://` 下 history 路由失效 |
| 首屏 | 不出现长时间白屏;异步数据视图必须有 loading 态 |
| 键盘可达 | Tab 顺序合理,焦点可见 |
| 缩放 | 浏览器 200% 缩放下不破版 |

## ③ 验收清单(Web 追加项)

- [ ] **多宽度可用**:375 / 768 / 1280 / 1600 四档均不破版。
- [ ] **宽屏约束**:超宽屏下内容有最大宽度,不无限拉伸。
- [ ] **浏览器验收**:用真渲染截图核对,不靠代码审查断言"应该没问题"。
